# Как сделать приложение для Android (APK)

*Приложение собирается из нашего сайта через бесплатный сервис PWABuilder (Microsoft). На iPhone так нельзя — там только установка через Safari или App Store (аккаунт Apple 99 €/год).*

1. Открой **pwabuilder.com** на компьютере.
2. Вставь адрес кабинета школы, например `https://reserva-tu-plaza.zkolra.workers.dev/querico/cuenta` (для Freedom — `/freedom/cuenta`) и нажми **Start**.
3. Предупреждения вроде «add screenshots» можно пропустить.
4. **Package for stores** → **Android** → **Generate Package** (настройки по умолчанию) → **Download**.
5. Скачается zip-архив. Внутри файл **.apk**, файл **assetlinks.json** и ключ подписи. **Сохрани весь архив** — ключ нужен для будущих обновлений.
6. Перекинь **.apk** на Android-телефон (Telegram самой себе, Google Drive или кабель) и открой его. Разреши установку из этого источника.
7. На экране появится иконка школы — приложение открывается как обычное.

**Убрать адресную строку сверху:** пришли Claude файл **assetlinks.json** из архива — он положит его на сайт (по адресу /.well-known/assetlinks.json), и Android поймёт, что сайт и приложение одного владельца.

Для каждой школы можно собрать своё приложение — со своим названием и цветом.
