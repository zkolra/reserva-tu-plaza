# Решения и идеи

*Что уже решено с владелицей продукта, что отложено и что — идеи на будущее.*

## Решения

- Слова «Leader» и «Follower», не «seguidor/líder».
- Пилот бесплатно. Каждая школа подключает свой Stripe (Stripe Connect), ключи никому не передаются.
- Письма уходят с домена Кати (сейчас mail.dev22.es), отправитель — название школы, ответ — на email школы.
- Залы необязательны: без залов — одно расписание.
- Пробное занятие: один класс, только новички, один раз.
- Матрикула действует, пока есть абонемент; сгорает через N дней без него.
- Продление: автоматически, помесячно или выбор ученика — решает школа.
- Абонемент по календарному месяцу по умолчанию; цена с середины месяца — пропорционально или по цене занятия; «начать с 1-го» — с дня N (решает школа).
- Годовых абонементов не делаем.
- Лист ожидания почти не нужен.
- Не Telegram, а приложение (PWA) с push-уведомлениями.
- Не Россия (санкции ЕС), а русскоязычная диаспора в Европе.
- iPhone: установка через Safari («На экран Домой»); App Store — позже (аккаунт Apple 99 €/год). Android: APK можно собрать через PWABuilder.
- Пароль нельзя показать (хранится зашифрованным) — показываем только «Ya tienes contraseña ✓».
- Не уговаривать школы: показать готовое.

## Роль «Ambos» (решено, в работе)

- В «Mi cuenta» и при покупке: Leader, Follower или **Ambos**.
- Если «Ambos» — выбрать **предпочитаемую роль** («prefiero leader»). Место считается по предпочитаемой роли.
- Роль на каждом классе отдельно не выбирается.
- Преподаватель видит «Ambos · prefiere leader» и знает, кого попросить встать за другую роль.
- Школа может выключить «Ambos».

## Частные уроки (на паузе)

Уже есть: преподаватели, опции с ценой по комбинации преподавателей (Solo Gabriel 60 €, Gabriel + Sirine 100 €), свободные часы по сетке, блокировки, бронь учеником и школой (по телефону), подтверждение вручную по желанию, пакеты, ссылка Jitsi для онлайн, шаг начала занятий и перерыв между ними.

Осталось: проверить весь путь, покупка и списание пакетов (нужен Stripe), оплата при брони, напоминания, письмо при брони школой, конфликт с групповыми классами преподавателя, недельный календарь броней, минимальное время до брони.

## Идеи на будущее

- **Отработки (recuperaciones)** по правилам Freedom: отмена минимум за 23 часа, отработать в течение 7 дней, на своём уровне или ниже, при наличии мест.
- **Новости для учеников** вместо организационных сообщений в WhatsApp.
- **Вечеринки и события** с билетами.
- **Email-рассылки** школы.
- **«Nos faltan leaders»** — позвать людей из других групп, если не хватает пары.
- **Напоминание в день занятия** push: «Hoy a las 20:00 — Salsa».
- **Добавить занятия в календарь** (Google / Apple).
- **Аренда залов** — на механизме частных уроков.
- **Спортклубы** — запись на каждое занятие (как Brooklyn Fitboxing).
- **Виджет** для чужого сайта школы — одна строка кода.
