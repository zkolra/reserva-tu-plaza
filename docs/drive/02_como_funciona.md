## Ученик

**Выбор классов и абонемента** (/школа)
- Недельное расписание со свободными местами; на телефоне — по дням (вкладки Lun, Mar…) и строка с ценой внизу.
- Несколько классов в одно время, залы, уровни, преподаватели.
- Роли Leader / Follower с отдельными местами (если школа включила роли). «Ambos» с предпочитаемой ролью — решено, в работе.
- Ученик отмечает классы — цена абонемента считается сама по числу классов в неделю. Full pass (∞) включается сам: с N классов или когда так дешевле.
- Абонемент по календарному месяцу: если начинает в середине месяца, платит пропорционально (или по цене занятия) и, если школа разрешила, может выбрать «начать с 1-го числа следующего месяца».
- Как платить: каждый месяц автоматически или «только этот месяц» — что разрешила школа.
- Матрикула: платится с первым абонементом, действует пока есть абонемент.
- Пробное занятие: один класс, только для новичков, один раз.
- Объявления сверху: отменённые занятия и дни без классов на 2 месяца вперёд.
- Если школа в тестовом режиме — оранжевая полоса «Estamos probando el sistema…» с её email.

**Mi cuenta** (/школа/cuenta)
- Вход по ссылке из письма или по паролю («Entrar más rápido»: создать пароль; браузер его сохраняет).
- Мой абонемент: классы, цена, с какого числа, до какого оплачено, как оплачен (онлайн / в школе).
- Если оплачен в школе: «¿Y después del 30?» — дальше платить в школе или картой автоматически.
- «Renovar diciembre» за 15 дней до конца (для помесячной оплаты) и «Pendiente de pago», если ещё не оплачено.
- Сменить классы, отказаться от автопродления / включить снова.
- Mis próximas clases — занятия на 7 дней, отменённые подсвечены, кнопки «Voy / No voy».
- Mi asistencia — сколько раз был в этом месяце и всего, последние отметки.
- История абонементов (отменённые помечены).
- Установить приложение на телефон и включить push-уведомления.

**Письма от имени школы** (с reservas@mail.dev22.es, ответ — на email школы)
- «Ya tienes tu plaza en …» — когда школа добавила ученика вручную.
- «Clase cancelada: …» — когда школа отменила занятие.
- «Tu abono termina el …» — за 5 дней до конца (каждое утро в 9:00).
- Ссылка для входа (через Supabase, тоже с mail.dev22.es).

**Push-уведомления** (в установленном приложении; на iPhone — только с иконки на экране)
- Тестовое при включении, «Clase cancelada», «Tu abono termina…».

## Преподаватель (вкладка Asistencia)

- Выбор дня; классы этого дня; у каждого — сколько записано из скольких, leaders/followers, сколько сказали «vienen».
- Список класса цветами: обычный — записан, оранжевая полоска — сказал «Voy», зелёный — пришёл, бледный — «No viene».
- Отметить пришедшего — нажать на имя (или «Vino / No vino»; «Todos vinieron»).
- Добавить человека без абонемента (гость, разовое, на будущие даты — с ролью).
- Отменить это занятие (с причиной и письмом + push всем записанным) или вернуть.
- Можно установить панель как приложение на телефон.

## Школа (админка /admin/школа)

| Вкладка | Что там |
|---|---|
| Asistencia | Списки классов по дням, отметки, гости, отмена занятия |
| Alumnos | Ученики с абонементом, «+ Añadir alumno» (наличные/перевод, с письмом-приветствием), «Dar de baja», «Pendientes de pago» → «Pagado ✓», пробные |
| Clases | Классы: название, уровень, преподаватели, день, время, длительность, зал, места (или отдельно leaders/followers); Salas (залы) |
| Precios | Абонементы по числу классов, ∞ Full pass, пробное занятие |
| Clases particulares | Модуль частных уроков (на паузе) |
| Apariencia | Цвет (8 вариантов) и логотип |
| Ajustes | Пароль, название, email школы, отмена за N часов, Modo prueba, Periodo del abono, Días sin clase (праздники), Full pass, матрикула, способ продления, роли, модули |

**Что школа может включить и выключить** (для будущего PDF)
- Роли Leader/Follower (и у каждого класса отдельно).
- Матрикула: сумма и через сколько дней без абонемента сгорает.
- Продление: только автоматически, только помесячно или выбор ученика.
- Период абонемента: календарный месяц или месяц с даты оплаты; цена с середины месяца — пропорционально или по цене занятия; с какого дня предлагать «начать с 1-го».
- Full pass: есть/нет, цена, с какого числа классов.
- Пробное занятие: есть/нет, цена.
- Залы: есть/нет.
- Отмена бесплатно до N часов.
- Тестовый режим.
- Модули: частные уроки (скоро: аренда залов, онлайн, оплаты).

## Катя (суперадминка /superadmin)

- Все школы, создание новой школы, доступ владельцам, вход в админку любой школы для помощи с настройкой.

## Как добавить новую школу

1. /superadmin → Nueva escuela (название и адрес, например «freedom»), дать доступ владельцу по email.
2. Либо подготовить SQL с расписанием и ценами (как seed_freedom.sql) и выполнить в Supabase.
3. В Ajustes: email школы, роли, матрикула, период, Modo prueba на время пилота.
