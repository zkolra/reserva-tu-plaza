# Reserva tu plaza

Sistema de reservas y pagos para escuelas de baile, profes y estudios, integrado en la web del cliente.

## Stack

- Next.js — web, panel del estudio, cuenta del alumno y widget
- Supabase — base de datos y acceso
- Stripe Connect — pagos directos a la cuenta de cada estudio
- Cloudflare — hosting

## Estructura

- `supabase/migrations/` — esquema de la base de datos
